# FairAge notebooks

Follow the [setup instructions](../README.md#install-and-use-the-environment), select the FairAge kernel in VS Code or Jupyter, and run the cells in order. The default workflows run on CPU. File exports are off by default.

| Notebook | What it shows |
|---|---|
| [01. Dataset exploration](01_dataset_exploration.ipynb) | FairFace counts by age and annotated race |
| [02. DeiT-Tiny walkthrough](02_vit_math_walkthrough.ipynb) | Patches, attention, and gradients with a synthetic image |
| [03. Results analysis](03_results_analysis.ipynb) | Learning curves, scores, and errors for five models |
| [04. Presentation figures](04_presentation_figures.ipynb) | All nine figures generated from published CSVs |

See [published results](../results/README.md) for the CSV contents.
